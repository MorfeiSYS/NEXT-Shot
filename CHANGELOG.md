# Changelog

## 1.0.31 — 2026-11-12

### Changed
- Вкладка «О программе»: удалена ссылка на skrinshoter.ru.

## 1.0.30 — 2026-11-12

### Changed
- Код приложения: `NEXTShot/NEXTShot/` → `NEXTShot/` (плоская структура).

## 1.0.29 — 2026-11-12

### Changed
- Брендинг в интерфейсе и инсталляторе: **NEXT-Shot** вместо «Скриншотер».
- Версия приложения отображается в шапке окна настроек; с вкладки «О программе» строка «Версия» убрана.

### Added
- Проверка обновлений через GitHub Releases (`MorfeiSYS/NEXT-Shot`).

## 1.0.28 — 2026-11-12

### Added
- Инсталлятор Inno Setup: `installer/NEXTShot.iss`, сборка `_tools/BuildInstaller.ps1` → `installer/output/NEXTShot-Setup-<версия>.exe`.
- Подготовка к GitHub: `.gitignore`, `README.md`, `LICENSE`, `NEXTShot.sln`.

### Fixed
- Путь к `_tools/FetchFfmpeg.ps1` в `NEXTShot.csproj` (лишний пробел в пути).
- Распаковка FFmpeg-архива в `FetchFfmpeg.ps1` (без `Expand-Archive -Force`, совместимо с Windows PowerShell 5.1).

### Removed
- Бинарники Скриншотера/scrrec в корне, `build-check`, артефакты сборки и `ffmpeg.exe` из репозитория (скачивается скриптом).

## 1.0.27 — 2026-11-12

### Fixed
- Запись области: кадры `CopyFromScreen` → pipe → FFmpeg (без `ddagrab`, который давал mp4 нулевого размера из‑за формата D3D11).
- Во время записи живое превью в рамке (~10 fps); режим записи включается только после успешного старта FFmpeg.

## 1.0.26 — 2026-11-12

### Fixed
- После выбора области картинка больше не «уменьшается»: рамка 2px не съедает внутреннюю область, размер кадра сверяется с захватом по DPI.
- Запись в области: клики проходят на рабочий стол внутри выделения (`HTTRANSPARENT`), превью и инструменты разметки отключаются на время записи.
- При записи в области оверлей исключается из захвата (`WDA_EXCLUDEFROMCAPTURE`), превью обновляется с рабочего стола (~8 fps) — в mp4 и на экране не остаётся «застывший» скриншот.

## 1.0.25 — 2026-11-12

### Fixed
- FFmpeg: чтение stderr без блокировки, чётные размеры кадра, корректный stop (`q`), удаление пустых mp4.
- Превью при записи области: без мигания всего окна (5 fps, без Opacity=0); панели скрыты на время записи.

## 1.0.24 — 2026-11-12

### Added
- `ffmpeg.exe` в проекте (`NEXTShot/ffmpeg/`), подтягивается `_tools/FetchFfmpeg.ps1` при сборке и копируется в `build-check`.

## 1.0.23 — 2026-11-12

### Changed
- Запись из трея — весь виртуальный экран; панель старт/стоп по центру снизу, перетаскивание, `WDA_EXCLUDEFROMCAPTURE`.
- Редактор области: запись без закрытия, блок перемещения рамки, живое превью, мигание кнопки; повторный клик — стоп, сохранение, закрытие.
- FFmpeg для области без `scale` (без сжатия кадра).

## 1.0.22 — 2026-11-12

### Added
- Кнопка записи в редакторе: старт/стоп FFmpeg по текущей рамке области (редактор не закрывается).
- Запуск только одного экземпляра NEXTShot (глобальный mutex).

## 1.0.21 — 2026-11-12

### Fixed
- Иконки на панели редактора снова отображаются: `ContentTemplate` + `ContentPresenter`, корректный pack URI для PNG в сборке.

## 1.0.20 — 2026-11-12

### Fixed
- Иконка «Стрелка» и остальные инструменты: переключение Normal/Checked через `ControlTemplate` и `CheckedSource`, без наследования `IsSelected` (стрелка не оставалась голубой).

## 1.0.19 — 2026-11-12

### Fixed
- Иконка «Стрелка»: `arrow.png` — Normal (чёрная), `arrow.checked.png` — Checked (голубая); раньше в неактивном состоянии мог подставляться Checked.

## 1.0.18 — 2026-11-12

### Changed
- При переносе/изменении рамки в редакторе содержимое превью обновляется в реальном времени (снимок экрана в начале жеста).
- Иконки инструментов: чёрные (Normal) / голубые (Checked), как в Скриншотере; `ExtractUi` выгружает пары `*.checked.png`.

## 1.0.17 — 2026-11-12

### Changed
- «Скриншот области»: после отпускания ЛКМ сразу открывается редактор (без второго подтверждения).
- Пока не выбран инструмент — область можно перетаскивать; маркеры и края рамки меняют размер (кадр переснимается).
- После выбора любой кнопки нижней панели (инструмент, толщина, цвет) перенос отключается, остаётся только ресайз.

## 1.0.16 — 2026-11-12

### Added
- «Скриншот области»: после первого выделения — маркеры по углам/сторонам, перенос и изменение размера.
- Подтверждение области отпусканием ЛКМ — затем захват кадра и панели инструментов.
- Клик вне рамки начинает новое выделение.

## 1.0.15 — 2026-11-12

### Fixed
- Скриншот всего экрана: размер области через `GetSystemMetrics` (физические пиксели), а не DIP `SystemParameters`.
- Панели инструментов при выходе за край оверлея смещаются во «внешнюю» зону и не пересекают выделение (в сохранённый кадр не попадают).

## 1.0.14 — 2026-11-12

### Changed
- Скриншот активного окна и всего экрана открываются в том же оверлее с панелями инструментов, что и «Скриншот области».

## 1.0.13 — 2026-11-12

### Fixed

## 1.0.12 — 2026-11-12

- Несколько размытий подряд: патч запекается в растр (без цепочки `BlurEffect`), рендер crop в software-режиме — штрихи не пропадают.

## 1.0.0 — 2026-11-11
